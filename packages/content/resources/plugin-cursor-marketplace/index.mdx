## What it is

The Cursor Official Plugin Marketplace is the first-party directory for discovering and
installing add-ons that extend the Cursor AI code editor. It centralizes MCP servers,
rules, and integrations so developers can wire external tools and data sources into
Cursor's agent and chat without hand-editing config files.

Because it is maintained by Cursor itself, listings are designed to install cleanly into
the editor and surface alongside Cursor's native settings.

## How to access / install

Browse the marketplace in any browser:

```
https://cursor.com/marketplace
```

You can also reach it directly from inside the editor via **Cursor → Settings → MCP /
Marketplace**. From a listing, use the one-click install action to add an entry to your
local Cursor configuration, then enable it in Settings.

## Good for

- Finding MCP servers that connect Cursor to APIs, databases, and dev tooling.
- Adding shared rules and integrations without writing config by hand.
- Keeping installed extensions discoverable and manageable from one trusted, official place.
