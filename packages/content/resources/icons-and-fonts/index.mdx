For **icons**, **Lucide** is the modern default with great framework packages. **Heroicons** pairs naturally
with Tailwind. **Iconify** gives you every icon set through one API when you need variety. For **fonts**,
**Google Fonts** has the biggest free catalog; **Fontshare** offers more distinctive designs for branding.
For stock photos and illustrations, see [Design Assets](/r/design-assets).
