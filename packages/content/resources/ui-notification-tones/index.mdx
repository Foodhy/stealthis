## Tonos de aviso

Paleta corta de sonidos de interfaz para confirmaciones, errores y bandeja. Cada tono se genera con osciladores y un soplo de ruido filtrado: no hay mp3 que alojar.

### Cuándo usarlo

- Un toast de éxito no debería sonar igual que un error destructivo.
- Las menciones y los mensajes directos merecen un ding más brillante que un aviso de sistema.
- El clic de “copiado” tiene que ser más corto que una notificación.

### Accesibilidad

El botón **Silenciar** corta el audio al instante. Si el sistema pide menos movimiento, el demo arranca en silencio. El audio solo empieza después de un gesto, como exige el navegador.
