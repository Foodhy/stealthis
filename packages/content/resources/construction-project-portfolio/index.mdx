## Project Portfolio

A hard-hat-ready portfolio page for a general contractor. Chunky condensed headings, steel and
concrete tones and a stripe of hi-vis yellow set the rugged trades tone. A filter bar lets visitors
narrow the grid by **Residential**, **Commercial** or **Renovation**, with a live project count.

Each card uses a gradient placeholder labelled with the build name, a type tag, the location and
the completion year. Clicking any card opens a lightbox-style detail overlay showing the full
scope, contract value, duration and a short description, dismissible by backdrop click, close
button or the Escape key.

All filtering, the live count and the lightbox are handled with plain vanilla JavaScript — no
frameworks, no build step. Drop the three snippets into any static page and adjust the data.

> Illustrative UI only — not for real construction bidding or contract use.
