## Project Detail

A rugged, trades-grade case-study page for a construction firm. It leads with a hi-vis status
banner and a hero gallery whose thumbnails swap the main image, then lays out the hard facts —
scope, duration, budget range and location — in a sturdy bordered fact grid.

Below the facts a challenge-and-solution narrative explains the brief and how the crew delivered,
followed by a tagged list of materials used. A draggable before/after teaser lets visitors wipe
between the demolition and the finished build, and the page closes with a steel-and-hi-vis
start-your-project call to action.

Everything is plain HTML, CSS custom properties and vanilla JavaScript — no frameworks, no build
step. Swap the placeholder copy and imagery for real project data and drop it straight into a
portfolio site.

> Illustrative UI only — not for real construction or engineering use.
