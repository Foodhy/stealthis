## Instagram Reels Template

A fully animated 30-second vertical Instagram Reels template built with Remotion. The composition opens on a vivid gradient background that shifts colors across the full duration — cycling from coral red through warm yellow into sky blue — giving the clip energy without needing real footage. An animated top progress bar tracks playback in real time. The creator's avatar circle and username fade and spring in from the top-left corner, immediately followed by a caption that builds word-by-word with a stagger typewriter effect and terminates with the hashtag line. On the right edge, four action icons — heart, comment, share, and save — stagger in from outside the frame with individual spring delays, each sitting inside a frosted circle with its counter label beneath. At the bottom a scrolling music ticker with a rotating note icon continuously marquees the song name across the full width, mimicking the native Instagram audio strip.

All configurable values — username, follower count, caption words, hashtags, song title, action counts, and gradient stops — are collected in a single `CONFIG` block at the top of the file for fast customization.

## Elements

- **Animated gradient background** — three-stop color shift (#ff6b6b → #feca57 → #48dbfb) cycling continuously across the clip duration
- **Top progress bar** — thin 3 px bar at the very top tracking playback from 0 % to 100 %
- **Creator header** — avatar circle (initials placeholder) + username "@pixel.dev" + follower count spring-in from frame 0
- **Caption overlay** — "when the code finally works ✨" text with per-word stagger fade-in; hashtag line below in a lighter tint
- **Right-side action icons** — heart (❤️ 847K), comment (💬 12.3K), share (➤ Share), save (🔖 Save) staggered slide-in from the right edge
- **Music ticker strip** — bottom bar with a rotating ♪ note icon and a continuously scrolling song name marquee animation
- **Global fade-out** — final 20 frames fade the entire composition to black
