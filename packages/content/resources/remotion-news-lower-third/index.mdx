## News Lower Third Bug

A broadcast-grade lower third composition that cycles through three distinct chyron styles in 120 frames (4 seconds at 30fps). Each variant occupies a 40-frame window and showcases a different production aesthetic — from the bold CNN-style red pillar card to the authoritative full-bleed political bar and the clean, modern floating capsule.

The simulated video background uses layered gradients, a subtle scanline texture, and a radial vignette to mimic a real camera feed — giving each lower third proper visual context. A pulsing LIVE dot and NNX News Network watermark reinforce the broadcast environment. All three variants share the same `GUESTS` data array, so swapping names, titles, and organizations is a single-file edit.

Animation quality is driven entirely by Remotion's `spring()` and `interpolate()` primitives. Variant 1 uses a spring slide-up entrance (`damping: 22, stiffness: 180`) with a separate red accent bar that scales from 0 to full width in 12 frames using an `Easing.out(Easing.cubic)` curve. Variant 2 wipes the full dark band in from the left via a `clipWidth` spring (`damping: 18, stiffness: 120`), with a gold top border that scales independently. Variant 3 layers a scale spring with an `interpolate` fade and a subtle sinusoidal float to give the white capsule a breathing, three-dimensional feel.

### Customization

- `GUESTS` — Array of `{ name, title, badge?, org? }` objects; one per variant. Swap in any names, titles, committee assignments, or org labels.
- `ACCENT_RED` — Primary broadcast red used in the CNN-style pillar, party badge pill, and capsule dot. Default `#e8001e`.
- `ACCENT_GOLD` — Gold used for the political name and dark-bar top border. Default `#f5c842`.
- `BG_DARK` / `BG_NAVY` — Background fill and gradient stops for the simulated video frame.
- `HOLD_FRAMES` — Number of frames each variant holds fully visible before exiting. Default `28` (~0.93 s at 30fps).
- `SPRING_SNAPPY` / `SPRING_SOFT` — Spring config presets (`damping` / `stiffness`) shared across entrance and exit animations. Increase stiffness for snappier motion; lower damping for more bounce.
- `SCENE1_START`, `SCENE2_START`, `SCENE3_START` — Frame boundaries for each variant. Change these to reorder scenes or extend hold durations.
