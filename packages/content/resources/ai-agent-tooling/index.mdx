Want your AI coding agent to use **fewer tokens** and understand your codebase better? These
open-source tools help: knowledge-graph indexers (graphify, codegraph) give agents a
queryable map of your code, caveman compresses output tokens, ponytail cuts code and cost
while speeding up runs, and rtk optimizes agent workflows.
