**Tailwind CSS** is the default for new projects — especially with [shadcn/ui](/r/ui-component-libraries).
**UnoCSS** if you want atomic CSS with faster builds. **Open Props** when you prefer CSS variables
over utility classes. **Bootstrap** for quick prototypes or teams already on it. For responsive QA
after styling, see [Responsive Design Tools](/r/design-dev-tools).
