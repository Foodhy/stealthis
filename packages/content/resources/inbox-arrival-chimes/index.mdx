## Campanas de bandeja

Tres llegadas, tres voces. El mensaje directo es un pop agudo, el correo son dos notas más cálidas y el sistema es un pulso grave. El contador de no leídos sube con cada una.

El modo en vivo las reparte cada pocos segundos para probar la bandeja sin pulsar. Páralo cuando quieras: el intervalo se limpia.
