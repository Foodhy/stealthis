# Tmux — Terminal Multiplexer Workflow

A copy-paste reference for running and managing tmux: persistent sessions, window
and pane layouts, the prefix key, copy mode, detach/attach, and a sane starter
config. Tmux keeps your shells alive on the server even when your SSH connection
drops, and lets you split one terminal into many.

## What this skill is

A condensed, accurate cheatsheet of the tmux commands you actually use day to day —
no exhaustive man-page dump, just the high-leverage keys and CLI invocations plus a
ready-to-use `.tmux.conf`.

## When to use it

Reach for tmux when you SSH into a remote box and want work to survive disconnects,
when you want several panes (editor, server, logs, REPL) in one window, or when you
want to name and reattach to long-running sessions later.
