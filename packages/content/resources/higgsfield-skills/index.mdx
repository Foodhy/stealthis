Agent skills for **image and video generation via Higgsfield AI**, including Marketing
Studio and the Virality Predictor video-scoring tool. They run across multiple AI coding
agents — Claude Code, Cursor, and Codex.

## How to install

```bash
npx skills add higgsfield-ai/skills
```

Alternatives: GitHub CLI (`gh skill install`), the Claude Code marketplace commands, or the
universal setup script in the repo.
