## Clinic Hours Card

A clean, brand-forward operating-hours card built entirely in Remotion — no external images, no CSS files, no Google Fonts. The dark `#0a1a18` background is warmed by two subtle radial glow orbs in teal that pulse softly through a sine wave, giving the composition a living quality without distracting from the information hierarchy. A large SVG clock in the header rotates its minute hand a full 360 degrees over the first 120 frames, serving as both a visual identity element and a natural motion anchor for the eye.

The hours list appears in three staggered rows — Monday–Friday, Saturday, and Sunday — each sliding up with a spring (damping 14, stiffness 120) offset by 8 frames to create a rhythmic cascade. A color-coded dot precedes each row: teal for open days, coral for the Sunday "Emergency only" state. Finally, at frame 90 a solid "Today is Open" status banner glides in from below using a spring translateY, centred on a green pulsing dot that breathes continuously once visible.

All clinic-specific text (name, hours, day labels) is declared as constants at the very top of the file so you can swap branding or adjust hours without touching animation logic. Change `SHOW_OPEN_BANNER` to `false` to hide the bottom status banner, or set `TODAY_IS_OPEN` to `false` to display a "Currently Closed" variant in coral.

### Customization

- `CLINIC_NAME` — swap the clinic display name in the header
- `TODAY_IS_OPEN` — toggle between "Today is Open" (green) and "Currently Closed" (coral) banner
- `SHOW_OPEN_BANNER` — set to `false` to hide the status banner entirely
- `HOURS` array — change day labels, time strings, and dot color per row
- `SPRING_CFG` — shared spring config object; stiffen or soften all transitions at once
- `BG`, `TEAL`, `CORAL` — top-level color constants; remap to any brand palette
