Build with the Data API

Every dataset is reachable over a versioned REST endpoint returning JSON, CSV, or Parquet. Anonymous access is rate-limited to 60 req/min; issue a free token for 5,000 req/min.

  • OpenAPI 3.1 schema & SDKs (Python, R, JS)
  • Stable DOIs & content-addressed snapshots
  • CORS-enabled, gzip + Brotli, HTTP range requests
