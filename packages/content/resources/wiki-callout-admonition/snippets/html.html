Callouts & Admonitions

Admonitions pull a reader's eye toward something that doesn't belong in the normal flow of prose — a caveat, a shortcut, or a warning that prevents data loss. Aurora DB's handbook ships five semantic variants plus a foldable details block. Use them sparingly; a page where everything is highlighted highlights nothing.

The five types

Each block carries a left accent border, a tinted background, an inline icon, and a bold title. Pick the variant whose meaning matches the message — the colour is part of the signal.

Note

Aurora DB stores timestamps in UTC internally. The at_zone() function converts on read, so a row written from Tokyo and read from Lisbon returns the same instant rendered in two different wall clocks.

Tip

Wrap multi-statement migrations in a single transaction. If the third ALTER TABLE fails, the cluster rolls the whole batch back and your schema never lands in a half-applied state.

Info

The default cluster ships with three roles. They differ in what they may write:

  • reader — read-only access to every namespace.
  • author — read plus write to owned namespaces.
  • steward — full control, including schema migrations.

Warning

Rebuilding a secondary index locks writes on the affected table. On the orders table at peak that can stall checkout for minutes — schedule it inside a maintenance window.

Danger

DROP NAMESPACE is irreversible and skips the trash. There is no soft-delete window and no undo — restore from a backup is the only path back. Double-check the target name before you press enter.

Collapsible details

Long supplementary content — full error tables, edge cases, the gnarly footnote — can fold away behind a toggle so it doesn't break a reader's stride. Activate the header with the mouse, Enter, or Space.

Idle connections are reaped after 30m by default. The pooler considers a connection idle when it hasn't issued a statement; an open transaction that never commits still counts as idle.

  • Raise the limit with SET idle_timeout = '2h'.
  • Or send a lightweight SELECT 1 heartbeat from the client.

Code inside a callout

When the actionable part of a callout is a command, embed a copyable code block. The copy button writes the snippet to the clipboard so the reader never has to hand-select it.

Tip — verify before you migrate

Dry-run a migration against a throwaway branch first:

aurora branch create --from main staging
aurora migrate --branch staging --dry-run
aurora migrate --branch staging --apply
