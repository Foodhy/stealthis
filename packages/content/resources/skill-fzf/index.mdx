# fzf — Fuzzy Finder with ripgrep

`fzf` is a general-purpose command-line fuzzy finder. It reads a list from stdin,
lets you filter it interactively as you type, and prints the selection to stdout.
Paired with `ripgrep` (`rg`) it becomes a fast, ergonomic way to find files,
search file contents, jump through history, and build interactive shell tooling.

## When to use it

Reach for fzf whenever you need to pick one item out of many: a file to open, a
git branch to check out, a command from your shell history, or a line of code
matching a search. Instead of typing exact names, you fuzzy-type a few characters
and let fzf narrow the list in real time.
