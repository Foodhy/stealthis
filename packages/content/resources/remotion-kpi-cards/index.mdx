## KPI Cards Animation

A five-second Remotion composition that presents four key business metrics as dark-themed cards against a deep cinematic background. The scene opens with the "Q4 Performance" section title sliding down into frame, followed by each card entering from below in a staggered sequence — 20 frames apart — driven by `spring()` for natural physical motion. Each card carries a distinct left-border accent color (indigo, cyan, emerald, amber) and a soft radial glow that bleeds into the dark background.

Inside each card the metric value counts up from zero using a second `spring()` curve, so the number accelerates quickly then eases to its final reading — $1.24M, 48,291 users, 3.8% conversion, $84 average order value. Once the count settles, a compact delta badge fades in revealing the quarter-over-quarter change. Positive deltas render in emerald, negative ones in rose, giving viewers an immediate visual reading of trend direction without needing to parse every number.

The layout is intentionally minimal: a subtle dot-grid overlay adds depth without distracting from the data, and two large blurred radial glows (indigo top-left, cyan bottom-right) give the composition warmth and prevent the dark background from feeling flat. No external fonts or assets are required — everything renders with `system-ui`.

### Data format

Metrics are defined as a `METRICS` constant array near the top of the file. Each entry follows the `KpiMetric` interface:

```ts
interface KpiMetric {
  id: string;           // unique key
  label: string;        // card heading, e.g. "Total Revenue"
  rawValue: number;     // the numeric target the count-up animates to
  displayValue: string; // final formatted string (used as fallback label)
  formatFn: (n: number) => string; // live formatter called each frame
  delta: string;        // delta text, e.g. "+12.4% vs last quarter"
  deltaPositive: boolean; // controls green vs red badge color
  icon: string;         // unicode symbol rendered in the card corner
  accentColor: string;  // left-border + icon color
  glowColor: string;    // rgba() string for the per-card background glow
}
```

To customize: replace the four entries in `METRICS` with your own labels, values, and `formatFn` callbacks. The card count is dynamic — remove or add entries and the flex row adjusts automatically.
