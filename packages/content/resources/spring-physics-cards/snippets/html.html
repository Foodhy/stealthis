How it works. Each card holds an x/y offset and a velocity. On release, a semi-implicit Euler step runs every frame: a = -k·x − c·v, then v += a·dt, x += v·dt — the same solver behind React Spring and iOS spring animations. Raise stiffness for a faster snap, lower damping for more overshoot.
