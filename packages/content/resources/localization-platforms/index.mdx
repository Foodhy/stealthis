Ship in multiple languages without hardcoding strings. **Crowdin** for collaborative translation
with Git and Figma sync. **Lokalise** for developer-first workflows with OTA mobile updates.
**Phrase** for enterprise TMS at scale. **Tolgee** for open-source in-context editing you can
self-host. If content lives in a CMS, see [Headless CMS](/r/headless-cms) for built-in localization.
