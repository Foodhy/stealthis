This topic is **mobile SDK analytics and attribution** — not general product analytics. For web
events, funnels, and session replay see [Product Analytics](/r/product-analytics). **Firebase
Analytics** for free in-app events on the Firebase stack. **AppsFlyer** and **Adjust** for
install attribution and marketing ROI. **RevenueCat** when subscriptions and IAP are the core
metric.
