An AI-powered **design-system generator** for Claude Code. It analyzes your project
requirements and recommends UI styles, color palettes, typography, and layout patterns
across 161 industry categories — and activates automatically for UI/UX requests (also works
in Cursor, Windsurf, and other assistants).

## How to install (Claude Code)

```text
/plugin marketplace add nextlevelbuilder/ui-ux-pro-max-skill
/plugin install ui-ux-pro-max@ui-ux-pro-max-skill
```
