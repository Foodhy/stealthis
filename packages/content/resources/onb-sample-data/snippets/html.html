How it behaves

  • Load demo data shows a brief skeleton, then fills the board with example deals and fires a toast.
  • Start from scratch dismisses the prompt and leaves the workspace empty.
  • Clear demo data reverts to the empty state and brings the prompt back.
  • The row counter is an aria-live region so the count is announced.
