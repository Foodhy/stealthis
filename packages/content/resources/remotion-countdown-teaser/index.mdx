## Countdown Teaser

A bold, vertical countdown teaser animation built with Remotion — designed for Instagram Reels, TikTok, and YouTube Shorts. The composition opens with a dark background punctuated by a pulsing indigo radial glow, then staggered title letters ("SOMETHING BIG IS COMING") slide down from above with spring physics. Three large number blocks — Days, Hours, and Minutes — flip into view in sequence, each simulating a split-flap display flip by compressing and re-expanding on the Y-axis. A pulsing ring orbits the Days block to draw the eye, while the bottom section reveals the event name "STEALTHIS 2.0 LAUNCH" beneath a glowing horizontal rule that sweeps in from the left. All colors, values, and copy are configurable via the constants block at the top of the file.

## Elements

- **Radial glow background** — dark canvas with a pulsing `#6366f1` radial gradient that breathes opacity 0.3 → 0.8 → 0.3 across the full duration
- **Staggered title text** — "SOMETHING BIG IS COMING" letters slide in from above with a spring entrance, each letter delayed by 2 frames
- **Three number blocks** (Days / Hours / Minutes) — large white digits on semi-transparent dark cards with a scaleY flip animation simulating a physical counter tick
- **Block labels** — "DAYS", "HOURS", "MINUTES" in small-caps beneath each number block
- **Pulsing ring** — animated concentric ring that scales and fades around the Days block, cycling to signal urgency
- **Glowing horizontal rule** — a line that sweeps in left-to-right above the event name using `interpolate` on width
- **Event name banner** — "STEALTHIS 2.0 LAUNCH" fades and scales up from below as the final reveal element
