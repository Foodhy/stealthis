## Contact & Quote

A sturdy, hi-vis contact block for a general contractor. The left column is a **request-a-callback**
form — name, phone, project type, job-site address and a short message — with inline validation that
flags empty or malformed fields, formats the phone number as you type, and confirms the request with
a success banner.

The right column carries the trust signals crews rely on: a **service-area map placeholder** marking
the coverage radius, a **business-hours table** with a live _Open now_ / _Closed_ pill computed from
the visitor's clock, and **licensed + insured badges** with license numbers.

Everything is vanilla HTML, CSS and JS — no libraries, no build step. Drop it into any page and wire
the form submit to your own backend or form service.

> Illustrative UI only — not a real contractor or binding quote.
