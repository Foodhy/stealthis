# Git Rebase — Interactive History Rewriting

A copy-and-go reference for rewriting Git history with `git rebase -i`. It covers the
interactive todo verbs (`squash`, `fixup`, `reword`, `edit`, `drop`, reorder), moving
branches with `rebase --onto`, automating cleanups with `--autosquash`, and getting your
work back with the reflog when something goes wrong.

## When to use it

Reach for interactive rebase when you want to tidy a feature branch **before** sharing it:
collapse "wip" commits, fix a typo in an old message, reorder logically, or surgically edit a
commit deep in the branch. Use `--onto` to transplant commits onto a different base.

## Use with care

Rebasing **rewrites commit hashes**, so only rebase commits you have not yet pushed to a shared
branch (or coordinate a force-push). If anything looks wrong, nothing is truly lost — `git reflog`
remembers where every branch pointed, so you can always reset back.
