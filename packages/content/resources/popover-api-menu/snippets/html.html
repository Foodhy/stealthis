Native Popover API Menu

Three overlay patterns — a dropdown menu, a tooltip, and a modal-style dialog — built with nothing but the popover attribute and popovertarget. The browser owns the top layer, light-dismiss and Escape. An @supports block adds CSS Anchor Positioning where available.

Dropdown menu

popover="auto"

Declarative trigger via popovertarget. Click outside or press Esc to light-dismiss. Anchored to the button with CSS anchor positioning when supported.

Hint tooltip

showPopover()

Same API, driven imperatively. Hover or focus the field label to reveal help text in the top layer — no z-index, no clipping by overflow.

Confirmation dialog

popover="manual"

A manual popover ignores light-dismiss, so it behaves like a modal. It still rides the top layer and gets a styled ::backdrop. Close only via its buttons.
