OpenCode — Open Source AI Coding Agent

An open source, terminal-based AI coding agent that is provider agnostic — bring your own model and extend it with MCP servers and custom agents.

How to access

# install the CLI
curl -fsSL https://opencode.ai/install | bash

# or via npm
npm install -g opencode-ai

# run it in your project
opencode
