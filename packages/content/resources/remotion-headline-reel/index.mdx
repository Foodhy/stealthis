## Headline Reel Animation

A cinematic news broadcast composition built entirely in Remotion and React. The 240-frame sequence presents four headlines in a strict sequential layout: each story occupies 55 frames with a spring-driven number badge entering from the left, headline text sliding in from the right, and a colored category pill fading up above the copy. At frame 40 within each story, the outgoing elements accelerate upward using an `Easing.in(Easing.cubic)` exit curve, making space for the next headline as it rises from below.

The layout uses a dark navy background (`#0a0e1a`) with a persistent top bar that carries the NNX News Network logo, a LIVE blink indicator, and the broadcast time. A segmented red progress bar runs along the bottom of the frame, filling one segment per story so viewers always know how far into the reel they are. Story transitions are punctuated by a brief red flash overlay for a broadcast-authentic feel.

After all four headlines have played (frame 220), the composition cross-fades into an end card: the network icon scales in with a spring, the network name fades in with a letter-spaced typographic treatment, and the URL pulses in last — giving the video a polished, shareable outro suitable for social media or broadcast packages.

### Customization

- `NETWORK` / `NETWORK_FULL` / `NETWORK_URL` — rebrand to any news channel name and web address
- `BROADCAST_TIME` — static time shown in the top bar (e.g. `"10:47 AM ET"`)
- `HEADLINES` array — swap in your own `{ number, category, categoryColor, text }` objects; `text` supports a `\n` line break for two-line headlines
- `ACCENT_RED` — primary brand color used for the top bar border, number badges, progress bar, and end card (default `#e8001e`)
- `BG_PRIMARY` / `BG_SECONDARY` — background colors for the main scene and end card
- `STORY_DURATION` — frames per headline (default 55, ~1.83 s at 30 fps)
- `STORY_TRANSITION` — frame within each story when the exit animation begins (default 40)
- `PROGRESS_BAR_COLOR` — color of the bottom progress bar fill
