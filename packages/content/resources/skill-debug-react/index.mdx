# React DevTools Debugging

A focused reference for getting the most out of the React Developer Tools browser
extension: the Components and Profiler tabs, inspecting live props/state/hooks,
visualizing re-renders, and measuring commit performance.

## What this skill is

A concise, copy-pasteable cheatsheet covering the day-to-day debugging loop in
React DevTools — finding a component, reading its props/state/hooks, spotting
unnecessary re-renders, and profiling slow commits so you know exactly what to fix.

## When to use it

Reach for this when a component renders the wrong data, updates too often, or feels
sluggish. The Components tab answers "what state is this in?" and the Profiler tab
answers "why is this slow?".
