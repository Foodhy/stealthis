# Browser Console Debugging Tricks

A compact reference for the browser DevTools console features that turn `console.log` debugging
into something actually fast: tabular output, grouped logs, styled messages, timers, element
selection helpers, and breakpoint utilities.

## What this is

A copy-pasteable cheatsheet covering `console.table`, `console.group`, `console.dir`, `%c`
styling, `console.time`, the `$0`/`$_` selection helpers, `copy()`, `monitor()`, `debug()`, and
live expressions. These are utilities built into Chrome, Edge, and (mostly) Firefox DevTools.

## When to use it

Reach for these when `console.log` alone is too noisy: inspecting arrays of objects, tracing
nested call flow, timing hot paths, or grabbing the currently inspected DOM node without
retyping a selector. Many of the helpers (`copy`, `monitor`, `$0`) only exist in the Console
itself, not in your shipped code.
