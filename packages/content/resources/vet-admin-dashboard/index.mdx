## Clinic Dashboard

A warm, at-a-glance admin view for a veterinary practice. Four KPI cards lead with animated counters
for **appointments today**, **patients seen this week**, **revenue** and **new patients**, each with
a delta badge versus last week. Below, a pure-CSS bar chart plots appointments across the week, an
appointments-by-type breakdown shows the case mix, and utilization meters track how busy each exam
room and vet is.

The recent-patients table lists real-sounding pets, owners, species, visit reason and a status badge
(Checked in, In exam, Ready, Discharged). A search box filters rows live and a segmented control
switches the bar chart between visits and revenue, all in vanilla JS with animated transitions.

The teal-and-coral palette, soft rounded cards and paw iconography keep it approachable while staying
dense enough for a real ops screen.

> Illustrative UI only — not for real veterinary use.
