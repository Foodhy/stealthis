# Shell Aliases & Functions That Save Time

A copy-pasteable reference for shortening the commands you type dozens of times a
day. Covers practical git, `ls`, and navigation aliases, the difference between an
alias and a shell function, where to put them so they persist, and how to write
parameterized functions.

## What this skill is

A curated set of `bash`/`zsh` aliases and functions you can drop straight into your
shell config. Aliases handle simple one-word substitutions; functions handle
anything that needs arguments, logic, or multiple commands.

## When to use it

Reach for it when you find yourself typing the same long command repeatedly, or
when setting up a fresh machine and you want a sensible starting `.bashrc` /
`.zshrc`. Every snippet is shell-builtin only — no extra tools required.

## Full cheatsheet

The complete, copy-pasteable cheatsheet lives in the snippet
(`snippets/markdown.md`): aliases, functions vs aliases, where to put them,
parameterized functions, common workflows, and gotchas.
