A template that transforms one Claude Code session into a **structured game-development
studio** — 49 specialized AI agents, 73 workflow skills (slash commands), 12 automated
validation hooks, and 11 path-scoped coding rules that enforce studio discipline on solo
game projects.

## What it covers

73 slash commands organized across onboarding, design, art, architecture, QA, production,
and release workflows.

## How to install

```bash
git clone https://github.com/Donchitos/Claude-Code-Game-Studios.git my-game
cd my-game
claude
/start
```
