## Animated Metric Counter

A focused, impact-first composition built around a single oversized number. The hero value — expressed in millions with a colored suffix — counts up from 0 using `interpolate()` with `Easing.out(Easing.cubic)`, decelerating smoothly as it approaches the target. The integer part is rendered at 200 px in white; the decimal portion fades to 25% opacity to visually de-emphasise it; and the "M" suffix glows in indigo (`#6366f1`) with a text-shadow bloom.

Two decorative lines animate in from the left and right edges using `spring()`, each terminating in a glowing dot and a short tick mark. A radial ellipse glow beneath the number pulses gently across the full 4-second duration by deriving opacity from a `Math.sin` wave keyed to the current frame. Below the counter, three supporting stat chips — Month-over-Month Growth, Churn Rate, and Paying Users — each spring up with a staggered delay starting at frame 60.

The dark background (`#0a0a0f`) is layered with a subtle 80 px CSS grid overlay at 1.5% white opacity, giving the composition depth without competing with the hero number. All colors are drawn from the project palette: indigo for the accent, emerald for positive growth, amber for the churn rate, and cyan for the paying-users chip.

### Data format

All metric values are hardcoded as constants at the top of the file. `METRIC` holds the single hero value (`target`, `prefix`, `suffix`, `label`, `subLabel`). `CHIPS` is an array of `{ label, value, color }` objects for the three supporting stat chips. To customise the composition, replace these constants — no prop drilling or runtime data needed for a standard render.
