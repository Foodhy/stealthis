software-engineering workflows, targeting alignment, verbosity, code quality, and
architecture. Covers test-driven development, architectural improvements, domain modeling,
and debugging.

## How to install

```bash
npx skills@latest add mattpocock/skills
```

Select the skills you want during setup.
