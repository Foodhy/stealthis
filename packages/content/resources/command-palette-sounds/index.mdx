## Paleta de comandos

Abrir es un soplo. Moverse con las flechas recorre un tic por comando. Enter confirma y deja el resultado escrito. Escape cierra con el tono de rechazo.

También puedes pulsar un comando con el ratón: suena igual que confirmarlo con el teclado.
