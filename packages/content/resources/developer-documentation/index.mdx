**Mintlify** for fast, polished API docs with OpenAPI sync. **ReadMe** for interactive developer
hubs with try-it explorers. **GitBook** for team wikis with a great editor. **Docusaurus** and
**Starlight** when you want open-source docs you host yourself — Docusaurus for React-centric OSS
projects, [Starlight](https://starlight.astro.build/) for Astro sites and monorepos that need
search, i18n, and performance out of the box.
