# Git Stash — Shelve Work in Progress

A focused reference for `git stash`: the command that lets you set aside uncommitted
changes on a clean working tree and pick them back up later. Perfect when you need to
switch branches, pull updates, or jump on a hotfix without committing half-finished work.

## When to use it

- You're mid-feature and need to switch branches for a quick fix.
- A `git pull` is blocked because of local changes you aren't ready to commit.
- You want to test how `main` behaves without your edits, then restore them.
- You experimented in the wrong branch and need to move the work elsewhere.

## What's covered

Named stashes (`stash push -m`), inspecting with `stash list`, the difference between
`pop` and `apply`, including untracked files with `-u`, stashing a single file, and
spinning a stash into its own branch with `stash branch`.
