FLIP Layout Animation

A reflowing grid where every item glides between layouts using the First · Last · Invert · Play technique — only transform and opacity are animated.

    How the FLIP technique works

    1. F First — before touching the DOM, record every item's current bounding box with getBoundingClientRect().
    2. L Last — mutate the DOM (reorder, filter, add) and let the browser reflow to the final layout. Measure the new boxes.
    3. I Invert — apply a transform that offsets each item back to where it started, so visually nothing moved yet.
    4. P Play — on the next frame, clear the transform with a transition. The GPU composites the slide — no layout thrash, no jank.

    Because only transform / opacity animate, the work stays on the compositor thread. Animating top/left/width instead would trigger layout on every frame.
