This is **cache and KV** — not SQL databases. See [Serverless Databases](/r/serverless-databases)
for Postgres/MySQL. **Upstash** is the default for serverless and edge Redis. **Vercel KV** if
you're all-in on Vercel. **Dragonfly** when you need maximum throughput with Redis compatibility.
