## Kitchen Prep Checklist

Pre-service checklist organized by station (Garde Manger / Hot Line / Pastry / Bar / Front of House). Each task has: checkbox, task description, assignee avatar chip, time estimate, and optional "critical" badge. A progress ring at top shows overall % complete. Filter by station or assignee. When all critical tasks are done, the "Sign off for service" button becomes active — tapping it logs the sign-off with timestamp.
