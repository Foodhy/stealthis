# Performance Profiling in the Browser

A copy-and-keep reference for diagnosing slow web pages with the Chrome DevTools
**Performance** and **Memory** panels. It teaches you how to record a trace, read a
flame chart, hunt down long tasks and layout thrashing, measure Core Web Vitals, and
capture heap snapshots to find leaks.

## When to use it

Reach for this when a page feels janky, scroll stutters, interactions lag, the tab's
memory keeps climbing, or your Lighthouse/CrUX scores flag poor LCP, INP, or CLS. The
goal is to move from a vague "it's slow" to a concrete frame, function, or allocation.

## What's inside

The full cheatsheet lives in the snippet (`snippets/markdown.md`). It covers panel
recording, flame-chart reading, long-task and layout-thrashing detection, the three
Core Web Vitals, memory snapshots, plus end-to-end workflows and common gotchas.
