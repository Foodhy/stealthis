# Git Worktree — Multiple Branches at Once

`git worktree` lets a single repository check out several branches at the same
time, each in its own directory. Instead of stashing your work to jump to another
branch, you spin up a second working tree that shares the same `.git` object store.

## When to use it

- A reviewer pings you for a hotfix while you are mid-feature — open the hotfix in a
  fresh worktree instead of stashing and switching.
- Run a long build or test suite on one branch while you keep coding on another.
- Compare two branches side by side in your editor or file explorer.

## What you get

Worktrees are cheap: they reuse the main repo's history and remotes, so there is no
re-clone and no duplicated `.git` data. Each worktree is locked to a distinct branch,
which keeps you from accidentally committing to the wrong place.
