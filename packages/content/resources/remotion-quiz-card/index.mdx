## Animated Quiz Card

A quiz card composition with three phases: Question phase (question text types on character by character using interpolate + substring), Answer reveal phase (four answer options A/B/C/D slide in from right staggered, each as a card), Reveal phase (correct answer card flashes green, wrong ones dim, "Correct! +10 pts" banner slides up, score counter increments).

### Composition specs

| Property | Value |
|---|---|
| Resolution | 1280 × 720 |
| FPS | 30 |
| Duration | 6 s (180 frames) |

### Usage

Copy `react.tsx` into your Remotion project, import `RemotionRoot` in your `Root.tsx`, and run `npx remotion studio` to preview.
