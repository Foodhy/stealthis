## Foil Card

A CSS-only foil pass. A wide angled highlight travels across the card, then pauses, like a stamped trading card catching light.

### How it works

An absolutely positioned `::after` uses a multi-stop linear gradient and `transform: translateX` inside `@keyframes foil-sweep`. Hover increases opacity so the sheen reads stronger without extra JavaScript.

### When to use it

- Pricing or rarity badges
- Static galleries where pointer tilt is too much
- Anywhere you want foil without tracking the cursor
