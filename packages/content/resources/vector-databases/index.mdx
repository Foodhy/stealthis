To build RAG or semantic search you store **embeddings** (vectors) and query by similarity.
Start with **Chroma** locally to learn, reach for **Pinecone** when you want a managed
service with no ops, pick **Qdrant / Weaviate / Milvus** when you want open source and
control, or use **pgvector** to add vectors to a Postgres database you already run. Compare
by type, hosting, and openness.
