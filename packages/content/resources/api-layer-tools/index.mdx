**tRPC** is the pick for TypeScript monorepos where client and server share types. **Apollo GraphQL**
when clients need flexible queries and a schema-first contract. **Hono** for fast HTTP APIs on the edge
(Cloudflare Workers, etc.). **OpenAPI** for public REST APIs that must work across languages and teams.
Pair with [State & Data Fetching](/r/state-data-fetching) on the client and
[ORM & Query Builders](/r/orm-query-builders) on the server.
