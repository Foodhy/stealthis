**GSAP** is the pick for scroll-driven and complex timeline animation. **Framer Motion** / **Motion** for
declarative React (or multi-framework) UI transitions. **Lottie** when designers export animations from
After Effects. For 3D and GPU graphics (not UI motion), see [JavaScript Graphics Libraries](/r/3d-web-libraries).
