// curriculum

16 weeks, four phases, one portfolio.

Each phase ends with a shipped, deployed project. You graduate with proof, not promises.

  1. 01

    Foundations

    Weeks 1–4

    HTML, CSS, modern JavaScript, the DOM, Git, and the command line. Daily kata and code reviews.

    JavaScriptGitCSS GridAlgorithms
    Ship: A responsive, accessible static portfolio site.
  2. 02

    Frontend Engineering

    Weeks 5–8

    React, component architecture, state management, testing, and real API integration.

    ReactTypeScriptVitestREST
    Ship: A live data dashboard with auth and tests.
  3. 03

    Backend & Databases

    Weeks 9–12

    Node, Express, SQL & Postgres, REST and auth, deployment pipelines, and observability.

    Node.jsPostgreSQLDockerCI/CD
    Ship: A full REST API powering a real product.
  4. 04

    Capstone & Career

    Weeks 13–16

    Build and deploy a production app with a team. Mock interviews, system design, and offer negotiation.

    Team buildSystem designInterview prep
    Ship: A team capstone deployed to production for Demo Day.
