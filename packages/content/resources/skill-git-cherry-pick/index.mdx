# Git Cherry-Pick — Apply Specific Commits

A focused reference for `git cherry-pick`: taking one or more commits from another
branch and replaying them onto your current branch without merging the whole branch.

## What this skill covers

Picking a single commit, a contiguous range, recording provenance with `-x`,
staging changes without committing via `--no-commit`, and the full conflict
loop (`--abort`, `--continue`, `--skip`).

## When to use it

Reach for cherry-pick when you need a specific bug fix or feature commit on a
different branch (for example backporting a hotfix to a release branch) but you
do not want to merge or rebase everything else that came with it.
