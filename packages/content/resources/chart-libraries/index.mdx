**Recharts** is the default for React dashboards with declarative SVG charts. **Tremor** when you want
pre-built dashboard blocks on Tailwind. **Chart.js** for framework-agnostic canvas charts with plugins.
**D3.js** when you need fully custom visualization and accept building from primitives.
