## Pie Chart Reveal

A 5-second Remotion composition that builds a donut chart segment by segment. Six fictional product lines — CloudCore, DataBridge, EdgeSync, VaultAPI, NovaSuite, and StreamKit — are each assigned a vibrant distinct color (indigo, cyan, emerald, amber, violet, rose). Every segment sweeps clockwise from its starting angle using a spring-driven arc, staggered 15 frames apart so the eye can follow each reveal.

The hollow center holds a live counter that increments in sync with the segment reveals, landing on the formatted total revenue figure once all slices are visible. Percentage labels burst out just beyond the arc edge with a spring overshoot after their parent segment finishes drawing. On the right, a legend slides in from the left — one row per product line, each showing the label, formatted dollar value, and percentage share — arriving in the same staggered order as the segments.

The composition uses a deep `#0a0a0f` cinema background with two layered radial glows (indigo/violet behind the chart, cyan behind the legend area) to give the dark canvas visual depth without distracting from the data.

### Data format

Each slice is defined by a `SliceDatum` object at the top of the file. Swap in your own categories, values, and hex colors:

```ts
interface SliceDatum {
  label: string;  // display name shown in legend
  value: number;  // raw numeric value (same unit across all slices)
  color: string;  // hex color for the segment, label, and legend dot
}
```

Change `STAGGER` (frames between each segment) to speed up or slow down the cascade. `DONUT_OUTER_R` and `DONUT_INNER_R` control the ring thickness. The center label denominator (`/ 1000`) and format string (`$…M`) should match your unit convention.
