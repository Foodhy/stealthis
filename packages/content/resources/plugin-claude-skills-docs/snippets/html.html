Claude Code (official)

Claude Code Skills (Slash Commands, Hooks, Agents)

Anthropic's official docs for packaging reusable capabilities — slash commands, hooks, and subagents — that extend the Claude Code CLI per project or globally.

How to access

https://code.claude.com/docs/en/skills 
# A skill lives in a SKILL.md file:
#   .claude/skills/<name>/SKILL.md   (project)
#   ~/.claude/skills/<name>/SKILL.md  (global)

# Invoke it from inside Claude Code:
/<skill-name>
