How it works

A tiny spring integrator advances a virtual x and width toward the active tab each frame. The indicator's travel velocity is mapped to a horizontal scaleX (squash) with a compensating vertical scale, so the element physically deforms in its direction of motion, then the spring's natural overshoot supplies the elastic settle. Both variants drive the identical engine.
