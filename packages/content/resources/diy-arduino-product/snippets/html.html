Small board, full-size peripherals

The Nano R3 keeps the 45 × 18 mm footprint of the family but swaps the 8-bit core for a 64 MHz 32-bit part with a hardware floating-point unit. That means PID loops, FFT windows, and sensor fusion run on-device instead of being shipped off to a host.

Power arrives over USB-C or the VIN pin (5–12 V), and an on-board buck regulator holds 3.3 V at up to 800 mA — enough headroom for a display, a radio, and a handful of sensors on the same rail. Every I/O pin is 5 V tolerant through series protection, so legacy shields keep working.

The board is published under CERN-OHL-S: schematics, Gerbers, and the bill of materials sit in the same public repository as the firmware bootloader.

  • USB-C with native device stackSerial, MIDI, and HID enumerate without a bridge chip.
  • Castellated edgesReflow the whole module onto a carrier PCB as a drop-in SoM.
  • 12-bit ADC ×8, 12-bit DAC ×1200 ksps sampling with an internal 1.024 V reference.
  • Hardware crypto blockAES-128, SHA-256, and a true random number generator.
  • Drag-and-drop bootloaderDouble-tap reset to mount a mass-storage drive and copy a UF2 file.

GETTING STARTED

From box to blinking LED in three steps

01

Install the core

Add the CIRCUITO board index in your IDE preferences, then install Circuito Nano Core from the boards manager.

02

Connect over USB-C

Plug the board in. The amber power LED lights immediately; the port appears as CIRCUITO Nano R3.

03

Upload the sketch

Paste the snippet, hit upload, and the green user LED on pin 13 starts its one-second cycle.

blink.ino 
void setup() {
  pinMode(LED_BUILTIN, OUTPUT);
  Serial.begin(115200);
}

void loop() {
  digitalWrite(LED_BUILTIN, HIGH);
  delay(500);
  digitalWrite(LED_BUILTIN, LOW);
  delay(500);
  Serial.println("nano r3 alive");
}
