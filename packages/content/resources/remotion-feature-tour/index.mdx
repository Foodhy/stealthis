## Feature Tour Video

A feature tour carousel: five feature cards cycle in sequence using Sequence components. Each card enters from the right (translateX 100→0), holds center, then exits left (translateX 0→-100). Cards show: large icon (emoji or Unicode symbol, 80px), bold feature title (48px), description (2 lines, muted), and a "Learn more →" ghost link. Progress dots at bottom highlight the active feature.
