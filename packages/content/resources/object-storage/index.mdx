This topic is **file buckets and uploads** — not image CDN transforms. For responsive images and CDN
optimization, see [Media Optimization](/r/media-optimization). **Cloudflare R2** is the cost-effective
S3-compatible pick (no egress). **AWS S3** is the enterprise default. **Uploadthing** abstracts uploads
for Next.js without touching buckets. **Supabase Storage** fits when you already use Supabase auth and RLS.
