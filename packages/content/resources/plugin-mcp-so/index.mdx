## What it is

mcp.so is a community-run directory of Model Context Protocol (MCP) servers. Per its
title it catalogs 19,000+ servers, making it one of the largest places to browse
the MCP ecosystem. Each listing gathers the server's purpose, install details, and
links so you can evaluate an integration before adding it to an AI coding tool.

It indexes directories and marketplaces of MCP servers — it is not a single plugin
itself, but a place to find them.

## How to access / install

Browse the directory in any web browser:

- Site: https://mcp.so/

There is nothing to install to use the directory. Once you pick a server, follow
that server's own setup instructions to register it with your MCP-capable client
(for example, by adding it to your client's MCP config or running its documented
command). The directory links out to each server's source and docs.

## Good for

- Discovering MCP servers for tools like Claude Code, Cursor, and other MCP clients.
- Comparing alternatives before committing to a particular integration.
- Staying current with a fast-moving, community-driven ecosystem.
