Claude Code (community)

awesome-claude-code-plugins

A community-curated directory of plugins, slash commands, and skills that extend Claude Code — a single index to discover, compare, and install integrations for the CLI coding agent.

How to access

# Browse the directory on GitHub
https://github.com/ccplugins/awesome-claude-code-plugins

# Or clone it locally
git clone https://github.com/ccplugins/awesome-claude-code-plugins.git

# Install a listed plugin from inside Claude Code
/plugin install <plugin-name>

Claude Code Slash commands Skills MCP servers
