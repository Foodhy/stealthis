# Vim Advanced — Macros & Registers

A copy-pasteable cheatsheet for the parts of Vim that turn it from a text editor
into an automation tool: recording and replaying macros, stashing text in named
registers, jumping with marks, batch-editing with `:g`, column edits with
visual-block, precise selection with text objects, and pattern rewrites with
`:s` backreferences.

## When to use it

Reach for these when you have a repetitive edit (rename across many lines,
reformat a list, reorder columns) that is too irregular for find-and-replace but
too tedious to do by hand. Macros plus `:g` cover most of that ground in seconds.

## What's inside

The full cheatsheet lives in the snippet (`snippets/markdown.md`). It is grouped
by feature — macros, registers, marks, `:g`, visual-block, text objects, and
`:s` with backrefs — and ends with end-to-end **Common workflows** and a
**Gotchas / tips** section.
