## Health Tip Animation

A vertical 1080 × 1920 Remotion card designed for clinic Instagram Stories and health-education reels. It opens with a large pill-capsule icon springing down from above — drawn entirely with inline SVG shapes — then reveals a daily hydration tip one word at a time against the deep clinic-dark background. The bold teal accent keeps every frame on-brand.

In the second half of the clip a horizontal progress bar fills from 0 % to 100 %, visualising a "Hydration goal: 8 glasses" metric. Each glass icon on the tracker lights up as the bar passes it, giving viewers a satisfying sense of completion. The animation closes with a softly-faded footer that carries the clinic name and series label, ready to drop straight into a Stories template.

All motion uses Remotion's `spring()` and `interpolate()` APIs — no CSS transitions — so the clip renders deterministically at any frame rate. Swap the constants at the top of `react.tsx` to change the tip text, goal count, clinic branding, or colour scheme in under a minute.

### Customization

- `CLINIC_NAME` — replace `"Greenfield Medical Center"` with your own brand
- `SERIES_LABEL` — change the sub-footer series descriptor (default `"Wellness Tips"`)
- `TIP_TEXT` — swap the tip sentence; the word-reveal engine handles any length automatically
- `GOAL_COUNT` — adjust the number of glasses (or steps, fruits, etc.) for the progress tracker
- `COLORS` object — override any palette token (`BG`, `TEAL`, `CORAL`, …) without touching layout code
- `durationInFrames` in `RemotionRoot` — extend to `180` if you want a slower word reveal
