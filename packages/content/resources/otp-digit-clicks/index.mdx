## Código con clics

Cada dígito es un clic corto y el retroceso, si la casilla está vacía, vuelve a la anterior con un tono más grave. Cuando las seis están llenas suena el acorde de éxito.

El foco avanza solo. No hace falta un botón de enviar para saber que el código ya está.
