Assemble

Frame, gearbox and servo horns. You work from a printed exploded map with torque values on every fastener, and finish with a dry-run gait on the bench cradle.

    gait_step.c servolab-gait 2.4 
    /* SL-01 — one gait step over the SL-Bus */
#include "slbus.h"

static const float STRIDE = 38.0f; // mm

void gait_step(Leg *leg, float phase) {
  float lift = clampf(sinf(phase), 0.0f, 1.0f);
  float x    = STRIDE * cosf(phase);
  float z    = leg->rest_z - lift * 18.0f;

  if (!ik_solve(leg, x, z)) {
    sl_fault(SL_ERR_REACH, leg->id);
    return;
  }
  sl_write_angle(leg->hip,  leg->q1);
  sl_write_angle(leg->knee, leg->q2);
}

    Firmware core

    Plain C, no hidden runtime

    The whole gait core is 640 lines you can read in one sitting. No block editor, no proprietary IDE — flash it with the same toolchain you would use for any Cortex-M board, then step it in a debugger.

    • Deterministic loop 1 kHz control tick with a measured 180 µs worst case.
    • One bus SL-Bus half-duplex, 32 nodes, daisy-chained.
    • Fault map Every servo reports stall, over-temp and reach errors.
    • Open licence MIT firmware, CERN-OHL hardware, published BOM.
