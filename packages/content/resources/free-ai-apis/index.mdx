New to API keys and tokens? These providers let you start **for free** — grab an API key,
drop it in your project, and call a model. Google AI Studio (Gemini) is the easiest, generous
start; OpenRouter gives you one key for many models (some free); Mistral, NVIDIA Build, Groq,
and Cohere each offer free tiers or credits. Compare what each gives you for free, then pick.
