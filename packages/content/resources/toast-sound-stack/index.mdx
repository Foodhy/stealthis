## Toasts con sonido

Una pila de notificaciones donde el color y el tono dicen lo mismo: verde y acorde para éxito, caída para error, dos notas para aviso, campana para info.

Cerrar un toast no vuelve a sonar. El aviso se retira solo a los pocos segundos y la región usa `aria-live` para lectores de pantalla.
