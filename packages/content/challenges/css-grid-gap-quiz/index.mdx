question: Which property adds spacing between rows and columns of a grid?
options:
  - margin
  - padding
  - gap
  - spacing
answer: 2
explanation: |
  `gap` (formerly `grid-gap`) sets the gutter between grid tracks. `margin` would apply to
  the grid container itself, and `padding` adds space *inside* the container, not between
  its tracks.
