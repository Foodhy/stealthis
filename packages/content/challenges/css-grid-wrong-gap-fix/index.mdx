starter: |
  <style>
    .stack {
      display: grid;
      grid-template-columns: repeat(2, 1fr);
      gap: 16;
    }
    .box { background: #cbd5e1; height: 60px; }
  </style>
  <div class="stack">
    <div class="box"></div>
    <div class="box"></div>
    <div class="box"></div>
    <div class="box"></div>
  </div>
solution: |
  <style>
    .stack {
      display: grid;
      grid-template-columns: repeat(2, 1fr);
      gap: 16px;
    }
    .box { background: #cbd5e1; height: 60px; }
  </style>
  <div class="stack">
    <div class="box"></div>
    <div class="box"></div>
    <div class="box"></div>
    <div class="box"></div>
  </div>
explanation: |
  Length values in CSS need a unit. `gap: 16` is invalid and the declaration is dropped —
  add `px` (or `rem`, `em`, etc.) so the browser actually applies the spacing.
---

The grid has no spacing between cells. Fix the broken declaration.
