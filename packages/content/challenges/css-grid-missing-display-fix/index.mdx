starter: |
  <style>
    .row {
      grid-template-columns: 1fr 1fr 1fr;
      gap: 1rem;
    }
    .cell { background: #ddd; padding: 1rem; text-align: center; }
  </style>
  <div class="row">
    <div class="cell">A</div>
    <div class="cell">B</div>
    <div class="cell">C</div>
  </div>
solution: |
  <style>
    .row {
      display: grid;
      grid-template-columns: 1fr 1fr 1fr;
      gap: 1rem;
    }
    .cell { background: #ddd; padding: 1rem; text-align: center; }
  </style>
  <div class="row">
    <div class="cell">A</div>
    <div class="cell">B</div>
    <div class="cell">C</div>
  </div>
explanation: |
  The container has grid-template-columns and gap but no `display: grid` — without it, the
  CSS Grid properties are ignored and the children stack as normal block elements.
---

The cells are stacking instead of laying out in three columns. Add the missing property.
