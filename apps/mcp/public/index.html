claude.ai · Desktop

Custom connector

Remote — nothing runs on your machine.

  1. Copy https://mcp.stealthis.dev/mcp.
  2. Open Settings → Connectors → Add custom connector.
  3. Name it Stealthis, paste the URL, click Add. The five tools show up in every chat.

Terminal

Claude Code

One command registers the server for every session.

$ claude mcp add stealthis --transport http https://mcp.stealthis.dev/mcp

Then put this in CLAUDE.md so the agent searches the library before writing UI from scratch:

Before writing any UI component from scratch, search the stealthis MCP server (tools: search, get_snippet) and adapt it to our design tokens.

mcp.json

Cursor

Add the HTTP server to your MCP config.

{
  "mcpServers": {
    "stealthis": {
      "type": "http",
      "url": "https://mcp.stealthis.dev/mcp"
    }
  }
}

Development

Remote by default, local if you hack on it

claude.ai always uses the hosted Worker. Run the worker yourself only when developing it:

$ bun run dev:mcp
# → http://localhost:8787/mcp

FAQ

Short answers

Do I need an API key or account?

No. The server is free and public. Add the URL and start prompting.

Which clients are supported?

Any MCP client that speaks Streamable HTTP: claude.ai, Claude Desktop, Claude Code, Cursor. REST lives at GET /tools/….

What do the tools return?

list_resources and search return catalog metadata. get_resource is one slug. get_snippet is source. get_lab is a live demo URL.

Remote or local?

Remote Cloudflare Worker at mcp.stealthis.dev. Local http://localhost:8787/mcp only when you run the worker yourself.

Where does the content come from?

The MIT-licensed Stealthis library, with demos on lab.stealthis.dev.
